# Testy

Każda lekcja ma krótki test z pytaniami zamkniętymi. Zaznacz odpowiedzi i naciśnij **Sprawdź odpowiedzi**: przy każdym pytaniu zobaczysz wtedy, czy odpowiedź jest dobra, i dlaczego. Najlepszy wynik zapisuje się w tej przeglądarce, a test jest zaliczony, gdy wynik osiągnie próg zaliczenia.

Przy każdym podejściu odpowiedzi są w innej kolejności. Rozwiąż test jeszcze raz kilka dni po przeczytaniu lekcji, żeby sprawdzić, czy wiedza została w głowie.

Żeby napisać albo zmienić test, zajrzyj do sekcji [Testy](../notes/01-start-here/01-how-this-works.pl.md#testy) w lekcji *Jak to działa*.
