# SFT

## What does SFT train on?

- [ ] Pairs of better and worse responses
- [x] Prompts paired with high-quality responses
- [ ] Rewards from checking the answer
- [ ] Raw text from the web

The model is trained to produce the responses in its examples. Pairs of responses are for RLHF and DPO, checked answers for RLVR, and raw text for pretraining.

## What loss does SFT use?

- [ ] Mean squared error
- [ ] A score from a reward model
- [ ] The next-token loss, counted only on the prompt
- [x] The same next-token loss as pretraining, usually counted only on the response

The model learns to write the response, not to predict the prompt.

## Why is SFT called *supervised*?

- [x] Every example comes with the answer to imitate
- [ ] People watch the model while it trains
- [ ] The model supervises its own training
- [ ] It's done only after a supervisor approves the model

In RL, by contrast, the model only gets a score.

## Why is SFT usually followed by RLHF, DPO or RLVR?

- [ ] SFT can't teach format or tone
- [ ] SFT needs millions of examples to work at all
- [x] The model imitates its examples, so it's limited by their quality
- [ ] SFT makes the model forget its pretraining

SFT is an efficient way to teach format, tone and instruction following, and datasets start at about a thousand carefully chosen examples. But because the model imitates its examples, their quality limits it.

## Where do the responses in an SFT dataset come from?

- [x] People write them
- [ ] They're sampled from the base model and used without checking
- [x] Other models generate them, and the best are kept
- [ ] They're copied from the web as they are

Responses are written by people or generated by other models and then filtered.
