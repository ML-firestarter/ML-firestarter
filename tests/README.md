# Tests

Every lesson has a short multiple-choice test. Pick your answers and press **Check answers**: each question then shows whether you got it right and why. Your best score is saved in this browser, and a test counts as passed once your score reaches the pass mark.

The answers come in a new order on every attempt. Retake a test a few days after reading the lesson to check that it stuck.

To write a test or change one, see [Tests](../notes/01-start-here/01-how-this-works.md#tests) in *How this works*.
