# Practice test

You've been through all the Basics lessons, and this test shows how much of them stuck. It has five tasks, from the easiest to the hardest, which you'll find below. Each one mixes things from several lessons, and says which, so that you know where to look if you get stuck. As in the lessons' exercises, **Check** tells you which parts of your code work, and once they all do, you can compare your code with our solution.

Here's what each lesson covered:

| Lesson                                                     | What it covered                                                                                  |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [Conditions and functions](01-conditions-and-functions.md) | variables, `input()`, `int()`, comparisons, `if`, `elif`, `else`, `and`, `or`, `not`, `def`, `return` |
| [Loops and dictionaries](02-loops-and-dictionaries.md)     | strings and indexes, `lower()`, `in`, `for`, `+=`, dictionaries, `items()`, f-strings            |
| [Ranges and lists](03-ranges-and-lists.md)                 | `%`, `range()`, `return` in a loop, `import math`, lists, `append()`, list comprehensions, `join()` |
| [Reading and writing files](04-files.md)                   | `open()`, `with`, `write()`, reading lines, `strip()`, `split()`, dictionaries of lists, `sorted()` |
| [Lists of lists](05-lists-of-lists.md)                     | slices, `list()`, `pop()`, lists of lists, a row that goes back and forth, `replace()`, `raise`  |

> [!TIP]
> Before you write a function, work out by hand what it should return for the examples in its task. If you can't do it by hand, the code won't do it either, and once you can, the code is often just the same steps, written down.
