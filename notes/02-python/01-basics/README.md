# Basics

Enough Python to write small programs of your own: make decisions, repeat work, keep values in dictionaries and lists, read and write files, and wrap it all up in functions.

Each lesson builds up to one program. It starts with what you'll write, explains the concepts it takes with examples you can run, and ends with an exercise in which you write the program and the page checks it. The lessons build on each other, so take them in order. The practice test at the end mixes them all, in five tasks from the easiest to the hardest.
