# Test praktyczny

Masz za sobą wszystkie lekcje z podstaw, a ten test pokazuje, ile z nich zostało ci w głowie. Ma pięć zadań, od najłatwiejszego do najtrudniejszego, które znajdziesz poniżej. Każde łączy rzeczy z kilku lekcji i mówi z których, więc wiadomo, gdzie szukać, gdy utkniesz. Tak jak w ćwiczeniach do lekcji, **Sprawdź** mówi, które części twojego kodu działają, a gdy działają wszystkie, możesz porównać swój kod z naszym rozwiązaniem.

Oto czego uczyła każda lekcja:

| Lekcja                                                  | Czego uczyła                                                                                      |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| [Warunki i funkcje](01-conditions-and-functions.pl.md)  | zmienne, `input()`, `int()`, porównania, `if`, `elif`, `else`, `and`, `or`, `not`, `def`, `return` |
| [Pętle i słowniki](02-loops-and-dictionaries.pl.md)     | napisy i indeksy, `lower()`, `in`, `for`, `+=`, słowniki, `items()`, f-stringi                    |
| [Zakresy i listy](03-ranges-and-lists.pl.md)            | `%`, `range()`, `return` w pętli, `import math`, listy, `append()`, wyrażenia listowe, `join()`   |
| [Odczyt i zapis plików](04-files.pl.md)                 | `open()`, `with`, `write()`, czytanie wierszy, `strip()`, `split()`, słowniki list, `sorted()`    |
| [Listy list](05-lists-of-lists.pl.md)                   | wycinki, `list()`, `pop()`, listy list, wiersz, który chodzi tam i z powrotem, `replace()`, `raise` |

> [!TIP]
> Zanim napiszesz funkcję, policz ręcznie, co powinna zwrócić dla przykładów z zadania. Jeśli nie umiesz zrobić tego ręcznie, kod też tego nie zrobi, a gdy już umiesz, kod to często po prostu te same kroki, zapisane po kolei.
