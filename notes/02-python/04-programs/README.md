# Programs

Bigger programs are made of parts that fit together. This chapter is about the way Python describes such parts, classes, and it's the Python that libraries like PyTorch and scikit-learn are written in.

Each lesson builds up to one program, as those of the Basics chapter do, and it assumes what they taught. More lessons are planned for this chapter, on modules and the standard library, and a project.
