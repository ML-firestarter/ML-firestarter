# Programs

Bigger programs are made of parts that fit together. This chapter is about the way Python describes such parts, classes, and it's the Python that libraries like PyTorch and scikit-learn are written in.

Each lesson builds up to one program, as those of the Basics chapter do, and it assumes what they taught. The chapter goes from classes to the modules of the standard library, and then to your own computer, where `uv` installs Python and the libraries a project needs. A project closes it, and puts the track together.
