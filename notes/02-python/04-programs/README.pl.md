# Programy

Większe programy składają się z części, które do siebie pasują. Ten rozdział jest o tym, jak Python opisuje takie części, czyli o klasach, i to w tym Pythonie pisze się biblioteki takie jak PyTorch i scikit-learn.

Każda lekcja prowadzi do jednego programu, tak jak lekcje rozdziału Podstawy języka, i zakłada to, czego one uczyły. W tym rozdziale planowane są kolejne lekcje, o modułach i bibliotece standardowej oraz o projekcie.
