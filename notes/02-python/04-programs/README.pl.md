# Programy

Większe programy składają się z pasujących do siebie części. Ten rozdział pokazuje, jak Python opisuje takie części, czyli klasy, a właśnie z klas zbudowane są biblioteki takie jak PyTorch czy scikit-learn.

Każda lekcja prowadzi do jednego programu, tak jak w rozdziale Podstawy języka, i zakłada znajomość tego, czego uczyły tamte lekcje. Rozdział prowadzi od klas przez moduły biblioteki standardowej do twojego komputera, na którym `uv` instaluje Pythona i biblioteki potrzebne projektowi. Zamyka go projekt, który łączy w całość wszystko, czego uczy kurs Pythona.
