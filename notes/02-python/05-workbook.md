# Workbook

The lessons teach one idea at a time, but a program usually needs several at once. This workbook has eighteen exercises to practise on, and each of them mixes ideas from the lessons in a way the lessons didn't: a dictionary with a file, a loop with an error, a list of lists with a game.

They go from the easiest, which takes a few minutes, to the hardest, which can take an evening. Each one says which lessons it draws on, so you know where to look when you get stuck. What each Basics lesson covered is listed at the start of the [practice test](01-basics/06-practice-test.md). The first twelve exercises draw on the Basics lessons. The last six also use the chapters on [errors and testing](03-errors-and-testing/README.md) and [programs](04-programs/README.md): classes, `csv`, `re`, `unittest`-style tests, `tomllib` and a program with a command loop.

You work on them as you do on the exercises at the end of the lessons. You write the code in the page, **Check** tells you which parts of it work, and once they all do, you can compare your code with our solution. Some exercises have a program under the functions that **Run** runs, and some of those read what you type in the input box.

The workbook is for practice, so it doesn't count toward a certificate. Take the exercises in order the first time through, and come back to the ones you want to practise more.

> [!TIP]
> When an exercise looks like too much, don't write all of it at once. Make the first check pass, then the next one. Each check shows the call it makes and what it expects, so you always know what to work on next.
