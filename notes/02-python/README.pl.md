# Python

Python to język, w którym powstaje uczenie maszynowe: PyTorch, scikit-learn, NumPy i pandas to biblioteki Pythona. Ten rozdział uczy go od zera, małymi krokami, i nie trzeba niczego instalować.

- **Uruchamiaj przykłady.** Kod w lekcjach ma przycisk **Uruchom**. Naciśnij **Edytuj**, żeby go zmienić i zobaczyć, co się stanie.
- **Rozwiązuj ćwiczenia.** Po każdej lekcji piszesz kod na stronie, a **Sprawdź** mówi, czy robi to, czego wymaga zadanie. Gdy przejdzie sprawdzenia, możesz porównać go z naszym rozwiązaniem.
- **Rozwiązuj testy.** Jak w innych rozdziałach, każda lekcja ma krótki test.

> [!TIP]
> Kod działa w twojej przeglądarce, więc pierwsze **Uruchom** pobiera Pythona, około 6 MB, i trwa kilka sekund. Potem startuje od razu. Więcej w lekcji [Jak to działa](../01-start-here/01-how-this-works.pl.md#ćwiczenia).
