# Errors and testing

Programs meet bad input, missing files and their own mistakes. This chapter is about what Python does when something goes wrong, how to handle it, and how to find the mistakes before your users do.

Each lesson builds up to a program or a function that you write at its end, as those of the Basics chapter do, and the lessons go in order: the second one's tests use what the first one's errors taught.
