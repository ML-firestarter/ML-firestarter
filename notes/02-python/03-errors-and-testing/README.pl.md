# Błędy i testowanie

Programy spotykają złe dane, brakujące pliki i własne pomyłki. Ten rozdział jest o tym, co robi Python, gdy coś pójdzie nie tak, jak sobie z tym radzić i jak znajdować pomyłki, zanim znajdą je użytkownicy.

Każda lekcja prowadzi do programu albo funkcji, którą piszesz na jej końcu, tak jak lekcje rozdziału Podstawy języka, a lekcje idą po kolei: testy z drugiej korzystają z tego, czego nauczyły błędy z pierwszej.
