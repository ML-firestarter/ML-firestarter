# Python

Python is the language machine learning is written in: PyTorch, scikit-learn, NumPy and pandas are all Python libraries. This chapter teaches you to write programs of your own in it, and there's nothing to install.

It starts past the very first steps: you should know that `print()` shows values, and how `+`, `-`, `*` and `/` work. Everything else is explained as it comes up.

## What you'll learn

[Basics](01-basics/README.md) has five lessons, each built around a program you write at its end, and a practice test:

1. [Conditions and functions](01-basics/01-conditions-and-functions.md): read an age, and say whether it belongs to an adult.
2. [Loops and dictionaries](01-basics/02-loops-and-dictionaries.md): count the vowels in a sentence.
3. [Ranges and lists](01-basics/03-ranges-and-lists.md): fix a program that finds prime numbers.
4. [Reading and writing files](01-basics/04-files.md): group the words of a file by their length.
5. [Lists of lists](01-basics/05-lists-of-lists.md): hide a message with the rail fence cipher.
6. [Practice test](01-basics/06-practice-test.md): five tasks that mix all of the above, from the easiest to the hardest.

## How the lessons work

Each lesson goes the same way:

1. **What you'll build.** It starts with the program you'll write at its end, and what writing it takes.
2. **The concepts.** One at a time, each with examples that run in the page. Press **Run** to run one, and **Edit** to change it and see what happens.
3. **Your turn.** The lesson ends with an exercise. You write the code in the page, and **Check** tests it and tells you which parts work. Once it passes, you can compare it with our solution.

> [!TIP]
> The code runs in your browser, so the first **Run** downloads Python, about 6 MB, and takes a few seconds. After that it starts right away. [How this works](../01-start-here/01-how-this-works.md#exercises) has more.
