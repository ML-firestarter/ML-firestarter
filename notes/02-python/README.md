# Python

Python is the language machine learning is written in: PyTorch, scikit-learn, NumPy and pandas are all Python libraries. This chapter teaches it from scratch, one small step at a time, and there's nothing to install.

- **Run the examples.** Code in the lessons has a **Run** button. Press **Edit** to change it and see what happens.
- **Solve the exercises.** After each lesson you write code in the page, and **Check** says whether it does what the task asks. Once it passes, you can compare it with our solution.
- **Take the tests.** As in the other chapters, each lesson has a short test.

> [!TIP]
> The code runs in your browser, so the first **Run** downloads Python, about 6 MB, and takes a few seconds. After that it starts right away. [How this works](../01-start-here/01-how-this-works.md#exercises) has more.
