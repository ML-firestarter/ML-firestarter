# Popraw trzy błędy

W tym programie są trzy błędy i każdy z nich zatrzymuje go z komunikatem o błędzie. Uruchom go, przeczytaj komunikat, popraw wiersz, który wskazuje, i uruchom program ponownie. Gdy poprawisz wszystkie trzy, program wypisze:

```text
Python 3
3 * 4 = 12
2 ** 10 = 1024
```
