# How long is a week?

A day has 24 hours, an hour has 60 minutes and a minute has 60 seconds. The program already prints how many hours a week has. Add two lines, so that it prints:

```text
7 d = 168 h
168 h = 10080 min
10080 min = 604800 s
```

Let Python do the arithmetic: write `7 * 24` rather than `168`.
