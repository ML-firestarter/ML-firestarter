# Ile trwa tydzień?

Doba ma 24 godziny, godzina 60 minut, a minuta 60 sekund. Program wypisuje już, ile godzin ma tydzień. Dopisz dwa wiersze, żeby wypisywał:

```text
7 d = 168 h
168 h = 10080 min
10080 min = 604800 s
```

Niech obliczenia wykona Python: pisz `7 * 24`, a nie `168`.
